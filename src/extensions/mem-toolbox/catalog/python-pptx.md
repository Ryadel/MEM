# python-pptx

- **kind**: library
- **capability**: read or write a PowerPoint deck
- **requires**: python
- **package**: `python-pptx`
- **import**: `pptx`
- **min version**: 1.0
- **purpose**: generate or edit `.pptx` decks from data — slides from a template's layouts, tables, images,
  charts.
- **invocation**: `from pptx import Presentation`
- **licence**: MIT, verified 2026-10-05 against <https://raw.githubusercontent.com/scanny/python-pptx/master/LICENSE>
- **url**: https://github.com/scanny/python-pptx

## Notes

- Work from a template deck. Layouts and placeholders come from the file; building a design from nothing in code
  is slow and fragile.
- It does not render: a slide cannot become an image or a PDF here.
- No release since 2024-08 (1.0.2). Stable, but check the issue tracker before relying on a recent format feature.
