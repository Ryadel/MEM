# Catalogue: documents

PDF, office formats and document conversion. See [index.md](index.md) for how to read this table.

| Capability | Candidates |
|---|---|
| Create a PDF programmatically | [reportlab](reportlab.md), [typst](typst.md) |
| Typeset a document to PDF | [typst](typst.md), [pandoc](pandoc.md) |
| Convert a document between formats | [pandoc](pandoc.md) |
| Merge, split, rotate or read a PDF | [pypdf](pypdf.md), [qpdf](qpdf.md) |
| Repair, linearise, encrypt or decrypt a PDF | [qpdf](qpdf.md) |
| Extract text or tables from a PDF | [pdfplumber](pdfplumber.md), [pypdf](pypdf.md) |
| Read or write a Word document | [python-docx](python-docx.md), [pandoc](pandoc.md) |
| Read or write an Excel workbook | [openpyxl](openpyxl.md), [pandas](pandas.md) |
| Read or write a PowerPoint deck | [python-pptx](python-pptx.md) |

`pandoc` is listed under "Typeset a document to PDF" only with an engine: it produces no PDF on its own.
